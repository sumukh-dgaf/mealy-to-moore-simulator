## 6. Numbering and adaptations

- The final M1 test plan (docs/milestone1/M1_Design_Document.md §14) lists TC-01 … TC-21; all 21 are automated here with the same IDs. TC-22 … TC-26 are new in M2 so that every README feature has a test. A letter suffix (TC-14a, TC-14b) marks separate checks inside one test.
- TC-02 planned "classic textbook machines from course material". No course-material answers were available to compare with, so three classic machines (complementer, running parity, overlapping 101 detector) were converted by hand and the program is checked against those hand results.
- TC-12 planned 500 random strings; it runs 500 seeded strings on each of 7 machines (3,500 comparisons). TC-21 reports the median of 5 timed runs.
- TC-13 (missing transition): the simulator rejects incomplete machines with one error per missing (state, symbol) pair. It never adds a trap state.
- Cross-checks are against hand-worked traces only (TC-01, TC-02a–c, TC-03a–b, TC-07, TC-09, TC-10, TC-11). No JFLAP cross-check was done.
